# ManuelW77 Homebrew Tap

```sh
brew tap manuelw77/tap
brew trust manuelw77/tap
brew install --cask schnittwerk
```

Homebrew only loads casks from taps you trust, hence `brew trust`.

| Cask | Description |
| --- | --- |
| [schnittwerk](https://github.com/ManuelW77/Schnittwerk) | Design and cut software for Silhouette Cameo plotters (Apple silicon, macOS 26) |

The cask is updated automatically by the Schnittwerk release workflow.
